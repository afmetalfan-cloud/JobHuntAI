# Fictional examples only

All candidate records here are invented. No source resume, employer history, contact detail, preference, or salary from a real participant is included. Salary fixtures are fabricated test values, and `example.invalid` URLs are deliberately unusable as research evidence.

`reference-session/` shows record relationships for tooling validation. It has no approved workflow state and is not a demonstration of an actual AI-run interview. `scenarios.json` defines four qualitative evaluation cases; execute those with a live assistant as described in evaluations/README.md.

Do not copy example facts into a person's session. Start from the blank templates.
