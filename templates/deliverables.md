# Deliverable outlines

Use the named files in the private outputs/ directory. Replace prompts with actual results; do not deliver these outlines as completed work.

## intake.md
Goal; starting materials; capability check; time estimate; planned rounds; uncertainties.

## interview-notes.md
Round/date; questions and answers; source IDs; confirmed facts; estimates; corrections; next questions.

## career-criteria.md
Required conditions; preferences ranked; learning interests; market; package priorities; timeline; unknowns.

## master-resume.md
Optional name/contact; verified summary; demonstrated skills; relevant role history and accomplishments; education/credentials; selected projects/volunteer work. Official titles stay accurate.

## open-questions.md
Question; affected claim/role; reason; next source or participant response needed. Explicitly state if no unresolved questions remain.

## role-map.md
Role family; direct/adjacent/stretch; supporting claim IDs; transferable skills; gaps; required credentials; training; constraint conflicts; rationale.

## compensation-report.md
As-of date; target market/currency; comparison table with links and duties; annualization assumptions; current-scope/external/stretch recommendations; separate negotiation target; confidence; limitations; package tradeoffs.

## profile-update-plan.md
LinkedIn headline/About/experience; skills-to-role mapping; visibility preferences; prioritized other websites with rationale; ready-to-use copy; manual steps; pending inputs; verification and action authorization.

## career-action-plan.md
Goal; next 7/30/90 days; weekly effort; owners; dependencies; success measures; networking/application or internal strategy; learning; 1/3/5-year scenarios; next review trigger; unresolved items.
